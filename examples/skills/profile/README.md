# Synthetic multi-session example (profile across sessions)

**Made up.** Four invented conversations in Spanish among four invented
people (Marta, Luis, Pablo, Irene), written for the project to exercise
`skills profile` (`docs/skills/DESIGN.md` §11). They describe nobody and
measure nothing.

| Session | Date | Kind | People |
|---|---|---|---|
| `perfil_s1` | 2026-10-06 | reunión de decisión | Marta, Luis, Pablo |
| `perfil_s2` | 2026-10-14 | resolución de problemas | Marta, Luis, Pablo, Irene |
| `perfil_s3` | 2026-10-23 | feedback | Marta, Luis, Pablo |
| `perfil_s4` | 2026-11-04 | negociación | Marta, Luis, Irene |

Hand-written sources:

- `sessions/<id>.txt`: the conversation, `[hh:mm:ss] Name: text`.
- `example.json`: person ids, session metadata, and for each person the
  level and evidence turns per competency (`[level or null, [[turn,
  indicator], ...]]`). No model wrote or rated anything.

Generated by `python experiments/skills/build_profile_example.py build`
(and checked by `... check` in the tests):

- `transcripts/<id>.transcript.v1.json`: as the transcriber would
  publish it, every speaker enrolled under the person id.
- `output/<id>.assessment.json`: as `skills assess` writes it. Every
  hand-written level passes the same evidence rules as a judge's
  (3 quotes from 2 separate exchanges, breadth at the extremes).

Page of one person:

```bash
uv run python -m src skills \
    --transcripts_dir examples/skills/profile/transcripts \
    profile --participant marta \
    --assessments_dir examples/skills/profile/output --synthetic
```
